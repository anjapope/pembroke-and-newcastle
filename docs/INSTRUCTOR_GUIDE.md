# Pembroke & Newcastle: instructor reference

## Purpose and outcomes

A fictional institutional acquisitions exercise for approximately 20 graduate
students working independently. All offerings, provenance and transactions are
simulated. Doris is a deterministic procedural reviewer, not a chatbot.

Students should be able to:

1. Relate acquisitions decisions to an institution's audience and mission.
2. Distinguish selection, saving, submission and processing.
3. Assign collection lines and fund accounting codes.
4. Explain tradeoffs among collecting priorities.
5. Account for annual budget constraints.
6. Correct procedural errors without abandoning professional judgment.

## Before class

Open <https://anjapope.github.io/pembroke-and-newcastle/> on the classroom network.
Confirm the footer says **PN-004 Classroom Simulation** and the catalog count is
**1,500 shared catalog records**. Each student needs a browser with JavaScript and
localStorage enabled. No installation or real account is required.

Use an invented Client ID and the password **collections**. Students invent
their institution, audience and collecting priorities. Public, academic and
museum profiles also require a department.

| Institution | Annual allocation |
| --- | ---: |
| Public Library | $5,000 |
| Academic Library | $8,000 |
| Archive / Special Collections | $4,000 |
| Museum / Cultural Heritage | $10,000 |
| School Library / Media Center | $3,000 |

Client IDs are labels, not shared accounts. State is local to the browser
profile, device and site origin. Use separate browser profiles/devices for
students; tabs in the same profile are **not independent student sessions**.
Private windows are separate from regular browsing but may share one private
profile with each other. Closing a private session normally discards its work.
There is no instructor dashboard, server account, central submission collection,
or real password security. Do not enter personal information.

## Suggested 20-minute individual exercise

- **Minutes 0-2:** Establish an institution. State its audience and two collecting
  priorities; note its annual allocation.
- **Minutes 2-7:** Browse the 1,500-record catalog. Combine category, format,
  keyword and price filters. Use Details to compare three different materials,
  including a potentially unconventional acquisition. Some unique offerings
  legitimately exceed the institution's budget.
- **Minutes 7-11:** Add materials, open the Order worksheet, and assign collection
  lines and funds. GENERAL is permitted; specialized funds have no separate
  balances. Add a brief selector note for an unconventional but defensible use.
  Save the requisition, then Forward from history.
- **Minutes 11-15:** Open Technical Services and explicitly request Review. Read
  Doris's findings. For a returned requisition, choose Edit and correct, save
  changes, then Resubmit and request Review again.
- **Minutes 15-20:** Observe exact committed and remaining amounts. Start a new
  requisition, process a second selection if affordable, refresh, and compare
  priorities with funds still available for the remaining eleven months.

For a reproducible rejection demonstration, a public library can assign an
adult nonfiction book to JF (Juvenile Fiction). Doris returns it. Change it to
ANF (Adult Nonfiction), save, resubmit, and review. A selector note cannot make
a clearly incompatible assignment acceptable.

## Suggested 10-minute institution-type discussion

In groups with the same institution type, compare audience assumptions,
collection-line choices, an expensive item declined, and priorities that remain
unfunded. Discuss why a manuscript or digital collection might be defensible
outside its customary institution, and what explanation is needed.

## Suggested 10-minute whole-class debrief

Compare allocations and tradeoffs across the five types. Ask:

- When did a selection become an expenditure?
- Did a correct accounting code imply a wise selection?
- What was gained or lost by an early substantial purchase?
- Which procedural corrections helped clarify professional judgment?
- What evidence would be needed to evaluate a real vendor's provenance?

## Doris and budget stewardship

Doris checks required fields, institution-authorized codes, collection/fund
compatibility, catalog quantities/prices and the remaining budget. She does not
judge the quality of a justification or whether an acquisition is intellectually
worthwhile. Unconventional assignments need a nonempty explanation; clearly
incorrect assignments require correction.

Only **processed** requisitions commit funds. Draft, saved, submitted and returned
requisitions do not reserve funds. Review is explicit and immediate. Reloading
or reviewing an already processed record cannot deduct funds twice.

At **80% cumulative annual use**, forwarding requires an explicit financial
acknowledgment. The scenario begins in January with eleven months remaining.
Archives, museums and schools additionally need a brief justification if a
single requisition uses at least 80% of the annual allocation. Public and
academic libraries may justify optionally. Exact remaining-balance expenditures
are allowed; overages are not.

Returned revisions retain the same ID. The revision selector in Requisition
details shows original submitted snapshots; correspondence records each review.

## Reset and troubleshooting

- **Reset:** Dashboard -> Reset Simulation -> read and confirm the warning. It
  clears this browser's profile, worksheet, requisitions, correspondence and
  budget history, then returns to login. The catalog and unrelated browser data
  remain unchanged. The next profile starts with its full annual allocation.
  Cancel leaves the exercise intact.
- **Logout also clears this browser's exercise.** Do not log out to preserve
  work; simply refresh or close a regular browser tab with site storage retained.
- **No results:** Clear catalog filters; check minimum/maximum price.
- **Cannot add after forwarding:** Start new requisition, or correct a returned
  requisition through Technical Services.
- **Doris has not reviewed:** Forward the saved record, open Technical Services,
  then use its Review action. Opening the page alone does not process orders.
- **Returned again:** Read the exact line and procedural reference; save all
  corrections before explicit resubmission.
- **Storage error:** Enable site storage/free browser space and retry. Do not
  promise persistence in private mode. A failed write does not count as success.
- **Wrong/stale release:** Hard-refresh and check the footer/catalog count.
  If the public URL is unavailable, check GitHub Pages deployment status before
  class; the site requires network access to load its code and catalog.
- **Different machine or browser:** It will not retrieve the earlier exercise,
  even with the same Client ID. No cross-device synchronization exists.
- **Narrow display:** Tables scroll horizontally; keyboard users can focus a
  labeled table region and use arrow keys. Escape closes item dialogs.

The simulation is not an acquisition system, rights clearance service,
conservation assessment, or real provenance register.
